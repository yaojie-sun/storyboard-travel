# Seedance-T 与 seedance-auto-doc 协作说明

## 概述
本文档说明了Seedance-T技能如何与seedance-auto-doc技能协作，特别是处理压缩文件格式的机制以及更新说明的展示功能。

## 文件格式兼容性

### seedance-auto-doc上传的文件格式
- 支持多种格式：`.md`、`.gz`（Gzip压缩）、`.zip`（ZIP压缩）
- 文件命名约定：`skill.md`、`skill_vX.X.X.gz`、`skill_updates.zip`

### Seedance-T的处理机制
1. **自动检测**：能够自动识别上传文件的格式（普通文本或压缩格式）
2. **智能解压**：支持Gzip和ZIP格式的自动解压
3. **格式透明**：无论原始文件格式如何，最终都转换为可用的技能内容

## 更新说明展示功能

### 更新说明获取
- 通过 `/api/v1/skill/changelog` 端点获取更新说明
- 在更新前后向用户展示具体的变更内容
- 提供详细的功能变更和改进信息

### 更新通知机制
- 更新前：显示更新内容预览
- 更新后：显示详细的更新完成通知
- 包含版本信息、更新时间和具体变更内容

## 更新流程

### 1. 文件发现
- 通过 `/api/v1/skill/files` 端点获取可用文件列表
- 根据文件扩展名判断是否为压缩格式
- 优先处理最新上传的文件

### 2. 下载与解压
```typescript
// 伪代码示例
const isCompressed = fileName.endsWith('.gz') || fileName.endsWith('.zip');
if (isCompressed) {
  // 自动处理解压
  const content = await decompressAndRead(fileBuffer);
} else {
  // 直接读取文本
  const content = await readAsText(fileBuffer);
}
```

### 3. 内容验证
- 解压后验证内容完整性
- 确保技能代码结构完整
- 验证安全检测机制是否保持完整

## 安全保障

### 更新前验证
- 检查文件来源是否可信
- 验证文件签名（如果可用）
- 确认用户登录状态

### 更新后验证
- 确保所有安全检测机制仍然有效
- 验证登录检查功能
- 验证次数检查功能
- 验证权限验证功能

## 错误处理

### 解压失败
- 尝试备用解压方法
- 回退到原始文件格式
- 提供详细的错误日志

### 内容损坏
- 保留之前的版本
- 提供错误报告
- 建议用户联系管理员
