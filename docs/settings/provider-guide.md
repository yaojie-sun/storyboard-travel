# 💡我该选哪个？
不需要全部都配置，选择一个最适合你的就可以了

1. [派欧云](https://ppio.com/user/register?invited_by=WGY0DZ)：稳定可靠的国内供应商，支持多种模型
2. [GRSAI](https://grsai.com)：价格实惠的国内供应商，注意接入点的区别
3. [火山引擎](https://www.volcengine.com/)：国内供应商，支持 Seedream 系列模型

---

# 💡我该怎么做？

1. 打开网站，注册一下
2. 找到 API 密钥（API KEY）管理页面
3. 创建并复制密钥
4. 将密钥填写到对应的供应商下面
5. 开始用吧！
