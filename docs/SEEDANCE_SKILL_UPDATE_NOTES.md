# Seedance-T 更新说明功能

## 概述
本文档说明了Seedance-T技能的更新说明功能，它能够获取并展示来自seedance-auto-doc技能同步的更新信息。

## 更新说明获取机制

### API端点
- **更新说明端点**：`GET http://47.108.237.10/jy/api/v1/skill/changelog`
- **数据格式**：JSON格式，包含更新说明、版本信息和变更列表

### 数据结构
```json
{
  "success": true,
  "changelog": "# 新版本更新 v1.2.0\n\n## 新增功能\n- 添加了新的分镜模板\n- 支持批量处理\n\n## 优化\n- 提升了处理速度\n- 改进了错误处理\n\n## 修复\n- 修复了内存泄漏问题\n- 修复了界面显示异常",
  "version": "1.2.0",
  "updatedAt": "2024-12-20T10:30:00Z"
}
```

## 功能实现

### 1. 更新前预览
在用户确认更新之前，显示即将应用的更新内容：
- 版本号
- 更新时间
- 变更列表
- 新功能说明

### 2. 更新后通知
更新完成后自动向用户展示：
- 已安装的版本号
- 完整的更新说明
- 新功能使用指南

### 3. 更新信息获取
提供API获取最新的更新信息，即使未进行更新也能查看：

```typescript
const updateInfo = await getLatestUpdateInfo();
if (updateInfo.hasUpdates) {
  console.log(`最新版本: ${updateInfo.version}`);
  console.log(`更新说明: ${updateInfo.notes}`);
}
```

## 用户体验

### 通知方式
- **模态对话框**：重要更新时显示
- **状态栏通知**：轻微更新时显示
- **详细日志**：所有更新的详细记录

### 通知内容
- 版本信息
- 更新摘要
- 新功能亮点
- 使用建议

## 安全与验证

### 内容验证
- 验证更新说明来源
- 确保内容格式正确
- 防止恶意内容注入

### 用户控制
- 允许用户跳过更新说明
- 提供详细的变更日志
- 支持更新说明的语言本地化

## API集成

### 获取更新说明
```
GET /api/v1/skill/changelog
Authorization: Bearer <token>
```

### 响应格式
```json
{
  "success": true,
  "changelog": "更新内容markdown格式",
  "version": "版本号",
  "notes": "简短说明",
  "updatedAt": "更新时间",
  "hash": "内容校验hash"
}
```

## 错误处理

### 网络错误
- 使用缓存的更新说明
- 提供离线可用的最后更新信息
- 自动重试获取更新

### 格式错误
- 降级到基础说明格式
- 提供默认更新消息
- 记录格式错误日志

## 隐私保护

### 数据收集
- 不收集用户查看更新说明的行为
- 仅记录必要的错误日志
- 不追踪用户对更新的反应

### 数据传输
- 使用HTTPS传输更新说明
- 验证服务器身份
- 防止中间人攻击

## 性能优化

### 缓存策略
- 缓存最近的更新说明
- 定期清理过期缓存
- 智能缓存更新检查

### 内容压缩
- 对长更新说明进行压缩
- 分块加载大型更新日志
- 按需加载详细信息
