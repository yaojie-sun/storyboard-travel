# 电商专版方案 — 产品介绍与使用短视频

## 定位

**"让每一款产品都有一条专业级的介绍视频"**

面向企业用户（品牌方/代运营/电商卖家），以上传的产品参考图为唯一视觉锚点，AI 自动理解产品属性并生成结构化展示视频。

核心差异化：**参考图 = 唯一视觉真相 + 文字 = 产品卖点表达**。与旅游版不同——旅游版侧重空间叙事和目的地氛围，电商版侧重**产品功能呈现和使用场景还原**。

## 五、SKILL.md 关键差异

### AI 角色
"电商产品展示专家" — 精通3C数码/家电/家居/食品/服饰/美妆的产品视频逻辑

### 核心能力
1. **产品卖点翻译**：将产品参数翻译为画面语言（"50000mAh电池" → "手机从红色电量充到满格的延时镜头"）
2. **材质还原**：根据不同产品材质（金属/玻璃/塑料/织物/皮革）匹配最佳光影方案
3. **使用场景构建**：为产品创造真实可信的使用场景，避免虚假感
4. **信息层级设计**：视频前3秒 → 痛点/好奇心，中间 → 功能展示，结尾 → CTA

### 强制规则（新增）
- **规则5：参考图锁定产品外观**。产品颜色/形状/Logo/材质100%锚定参考图，禁止修改
- **规则6：禁止虚假演示**。功能描述必须有对应的画面呈现，禁止凭空夸大
- **规则7：文字卖点可视化**。每个卖点必须有画面呈现——"防水"需要水花镜头，"快充"需要电量动画，"降噪"需要分贝对比

### 负面提示词（电商专用）
```
product deformation, color shift, logo blur, texture loss, false reflection,
unnatural physics, floating product, brand misprint, size inconsistency,
material mismatch, packaging damage, CG feel, plastic texture, 3D render,
overexposed white background, ghost product shadow, AI watermark
```

## 六、与旅游版的系统差异

| 维度 | 旅游版 | 电商版 |
|------|--------|--------|
| 核心叙事 | 空间递进（外→内） | 产品认知旅程（外观→功能→价值） |
| 参考图角色 | 目的地锚定 | 产品外观唯一真相 |
| 文字角色 | 运镜+环境描述 | 产品卖点+功能翻译 |
| 光影重点 | 黄金时刻/蓝调时刻/自然光 | 产品布光（侧光/柔光箱/环形光） |
| 真实感 | 禁止CG感（写实旅游摄影） | 禁止CG感+材质失真+Logo模糊+颜色偏移 |
| 音频 | 环境音强制（海浪/鸟鸣） | 产品音效+讲解VO+BGM |
| 视频长度 | 12-15秒 | 8-30秒（视复杂度） |
