# 服饰专版方案 — AI 服装展示短视频

## 定位

**"让每一件衣服都有自己的模特秀"**

面向服装品牌/设计师/电商卖家/穿搭博主，以服装参考图为唯一视觉锚点，AI 理解服装属性（版型/材质/风格/穿着方式）并生成专业级服装展示视频。

核心差异化：**服装 = 唯一主角，人物 = 服装的载体**。运镜/走位/动作全部服务于"展示服装"，而非"展示人物"。

---

## 二、视频类型（6种）

| 类型 | 适用场景 | 参考图要求 |
|------|---------|-----------|
| `catwalk` | T台/走秀风格 | 全身正面+侧面+背面 |
| `outfit` | 整套搭配展示 | 上下身搭配+配饰 |
| `detail` | 面料/细节特写 | 领口/袖口/纽扣/刺绣等微距 |
| `mixmatch` | 一衣多穿/搭配 | 同一单品+不同搭配 |
| `lookbook` | 画册风静态展示 | 多套服装的白底/场景照 |
| `fabric` | 面料动态展示 | 面料飘动/垂坠/透光 |

核心叙事逻辑：**"服装的完整呈现旅程"** — 从整体到细节、从静态到动态、从单套到搭配

| 宫格 | 走秀 | 搭配 | 细节 | 一衣多穿 | 画册 | 面料 |
|------|------|------|------|---------|------|------|
| 1 Hook | 全身正面定妆 | 整套LOOK正面 | 服装整体定位 | 单品+搭配1正面 | 第一套正面 | 面料自然垂坠 |
| 2 Context | 侧面展示廓形 | 上半身搭配 | 领口/肩部特写 | 单品+搭配2正面 | 第二套正面 | 面料迎光透射 |
| 3 Demo | 背面展示线条 | 下半身搭配 | 袖口/纽扣微距 | 单品+搭配3正面 | 第三套正面 | 面料飘动动态 |

| 5 Outcome | 转身动态瞬间 | 整体搭配场景化 | 刺绣/印花特写 | 搭配2场景化 | 模特情绪特写 | 面料折叠垂坠 |

## 五、人物走位与动作规范（核心差异化）

### 走位路径

| 路径 | 说明 | 适用 |
|------|------|------|
| 直线前进 | 人物从远处走向镜头，停止后转身 | 走秀/全身展示 |
| L型转身 | 前进→左转→侧面→继续前进 | 侧面+正面过渡 |
| 圆形环绕 | 人物固定，镜头环绕 | 360°展示 |
| S型曲线 | 人物走S形路线，镜头固定 | 裙摆/飘逸面料 |
| 坐姿切换 | 站立→坐下→起身 | 裤装/半身裙弹性展示 |

### 动作规范

| 动作 | 目的 | 时长建议 |
|------|------|---------|
| 自然转身 | 展示背面设计 | 1-2秒 |
| 单手插袋 | 展示口袋/腰部设计 | 0.5-1秒 |
| 轻抚面料 | 展示材质触感 | 0.5-1秒 |
| 整理衣领/袖口 | 展示细节设计 | 0.5-1秒 |
| 回眸 | 展示背面+肩部线条 | 1-1.5秒 |
| 自然行走 | 展示服装动态垂坠 | 2-3秒 |
| 轻微摆动 | 展示裙摆/下摆动态 | 1-2秒 |

### 人物规则（强化服饰展示）

- **人物面部不占视觉焦点**：面部占比不超过画面20%，服装占比60%以上
- **禁止复杂表情**：保持自然中性，不抢服装戏份
- **动作速度匹配服装风格**：正装慢速优雅，休闲装自然随意，运动装活力明快
- **发型/妆容服务于服装**：不遮挡领口/肩部/背部设计

## 六、SKILL.md 关键差异

### AI 角色
"服装展示导演" — 精通女装/男装/童装/运动装的T台秀、LOOKBOOK拍摄和电商白底图展示

### 核心能力
1. **服装版型理解**：A型/H型/X型/O型廓形 → 不同的镜头语言
2. **面料语言翻译**：雪纺→飘逸感（慢动作）、牛仔→挺括感（固定镜头）、针织→垂坠感（侧面波浪）、丝绸→光泽感（侧光+微距）
3. **穿搭逻辑**：色彩呼应/层次叠穿/配饰点缀 → 镜头如何呈现
4. **模特调度**：走位路线/转身时机/动作节奏 → 全部服务于服装

### 强制规则（新增）
- **服装=唯一视觉主角**。人物面部占比<20%，服装占比>60%
- **面料动态强制呈现**：飘逸面料必须有飘动镜头，垂坠面料必须有垂直下落镜头
- **禁止改衣**：服装的颜色/版型/长度/图案100%锁定参考图
- **动作自然主义**：禁止浮夸T台姿势，动作如同日常穿着

### 负面提示词（服饰专用）
```
garment deformation, fabric pattern drift, color bleeding, logo smear, 
button misplacement, zipper distortion, seam misalignment, collar warp,
pocket disappearance, hemline fluctuation, print blur, embroidery ghosting,
wrinkle removal (natural fabric wrinkles allowed), plastic mannequin look,
rigid fabric simulation, unnatural drape, floating garment, headless mannequin
```

## 七、与旅游版&电商版的差异

| 维度 | 旅游版 | 电商版 | 服饰版 |
|------|--------|--------|--------|
| 叙事逻辑 | 空间递进 | 产品认知旅程 | 服装呈现旅程 |
| 视觉主角 | 目的地 | 产品 | 服装 |
| 人物角色 | 游客/体验者 | 用户/演示者 | 模特/穿着载体 |
| 运镜核心 | 无人机/POV | 旋转/微距 | 跟拍/环绕/面料特写 |
| 光影重点 | 自然光/黄金时刻 | 产品布光 | 时装布光（柔光/轮廓光） |
| 真实感 | 旅行摄影 | 产品摄影 | 时装摄影 |
| 视频时长 | 12-15秒 | 8-30秒 | 8-20秒 |
| 音频特征 | 环境音 | 产品音效+VO | BGM+T台节奏+布料摩擦声 |
